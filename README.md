1. Project Overview
This is a fully responsive frontend car sales website developed and refined using GenAI tools. It includes complete navigation, form validation, car search, car image display, and a consistent glassmorphism design.
2. Key Features
Responsive layout for desktop and mobile
Login & registration with client-side validation
Add car information page
Search cars by model and year
Display car list with local images
Unified navigation bar and visual style
3. Pages Included
home.html
Login.html
registration.html
addcar.html
Search.html
4. Teamwork & Development Process
Group discussion to define requirements and AI prompts
Each member responsible for one page and AI iteration
GitHub workflow used: feature branches → develop → main
Regular meetings to evaluate AI code, fix issues, and refine prompts
Improved image display, text readability, layout consistency, and visual effects
5. How to Run
Place all HTML files and images in the same folder, then open any HTML file in a browser.
6. Tech Stack
HTML5, CSS3, JavaScript, GenAI, GitHub Version Control
